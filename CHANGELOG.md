# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/), and this
project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-22

### Added

- Device, System, CPU, Memory, Storage, Battery, Display, GPU, Network and
  Sensors information sections.
- Dark Material 3 interface with a shareable text report export.
- Signed release APK (Android 8.0+, minSdk 26).
- Zero dependencies beyond AndroidX AppCompat and Material Components.
